    The three ideas
    
    
    
      
    1 · One job, one worker
    Two workers ask at the same moment. The database gives the first job to one of them. The other one skips that row and takes the next job. It does not wait. This is FOR UPDATE SKIP LOCKED.
    
      
    2 · A lease is a lock with an end time
    A worker holds a job for 60 seconds. If it is alive, it asks for more time (heartbeat). If it dies, nobody asks, the time ends, and the reaper gives the job back.
    
      
    3 · The attempt number is a ticket
    Each time a job is taken, attempts goes up by 1. A worker must show its ticket to finish the job. An old ticket is refused. This is called a fencing token.
