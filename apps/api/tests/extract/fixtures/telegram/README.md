# Telegram fixtures

Made-up values in the form of the real embed pages of Telegram (`https://t.me/<channel>/<post>?embed=1&mode=tme`),
as they were on 15 October 2026: the classes of the message block, its text, link preview, photos,
video, views and date, and the page of a post that does not exist. The scripts and the pictures of
the real pages are left out. No text of a real post is here.

`tests/extract/test_telegram_live.py` checks the form of real pages (`-m live`).
